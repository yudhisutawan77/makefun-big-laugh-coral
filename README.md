## The line

> My bank flagged 'unusual activity' on my account — turns out it was me buying groceries instead of takeout, the first responsible thing I've done all year.

## How it works

`main.py` prints the one-liner to stdout and writes it to `$ENTRY_OUT`,
handling `ENTRY_OUT` as either a file path or a directory (writing
`entry.txt` inside it), defaulting to `/output/entry.txt`. The line is
a single line of 200 characters or fewer, as the bounty requires.

Run it:

```sh
ENTRY_OUT=/output/entry.txt python3 main.py
```
